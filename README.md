# DPS3D — AI 스마트팩토리 자동 품질검사 시뮬레이터

3D융합설계과(AI융합설계과) 전교생 투어를 위한 **자동 반복 재생형** 웹 시연입니다.

## 실행
- [시뮬레이터 열기](./index.html): HTML 파일을 내려받아 브라우저에서 실행하거나 GitHub Pages 등 정적 웹 호스팅 서비스에 게시합니다.
- 컴퓨터와 모니터만으로 실행할 수 있으며 카메라, 센서, 서버가 필요하지 않습니다.
- 일시정지, 재생속도, 전체화면을 사용할 수 있습니다.

## 주의
**실제 학습된 AI가 판정하는 시스템이 아닙니다.** 사전 설정된 가상 검사 데이터를 시각화한 시뮬레이터입니다. 실물 검사 AI와 혼동되지 않도록 안내해 주세요.

## 수정
메인 웹 페이지 코드는 `index.html`입니다. 색상, 문구, 애니메이션과 판정 연출은 이 파일에서 수정할 수 있습니다.
